# Mobile interface conventions

Use the shared SVG arrow with the ui-arrow class for directional icons in links, buttons, and dialogs. Keep decorative icons hidden from assistive technology and label icon-only controls. Avoid Unicode arrow glyphs and emoji for interface icons. Before publishing mobile changes, check narrow phone layouts and confirm icons inherit the text color, including on iOS Safari when available.

Client testimonial photos must show their complete frame using object-fit: contain and natural height. Check both portrait and landscape photographs when changing the carousel layout so faces remain visible on desktop and mobile.
